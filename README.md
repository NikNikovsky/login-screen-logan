## Live Demo

This login screen is automatically deployed to GitHub Pages, it might take a few minutes to show up after comitting, please be patient. Visit the live demo at:
`https://niknikovsky.github.io/login-screen-logan/`

## Features

- Clean, modern login interface
- Responsive design that works on all devices
- Username and password input fields
- "Forgot Password" link
- Author credit for background design

## Local Development

To run locally, simply open `index.html` in your browser or serve it with a local web server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/` in your browser.

## Deployment

This site automatically deploys to GitHub Pages on every push to the main/master branch via GitHub Actions.
